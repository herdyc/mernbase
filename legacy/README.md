# Legacy: original mernbase

The first version of this repo: a MERN starter template (Create React App + Express + Mongoose). It is kept here for reference only and is **not maintained**.

It has been rewritten as [rung 3](../03-mern) of the Stack Ladder, which fixes the empty auth files, replaces Create React App with Vite, adds tests, and connects to MongoDB before accepting requests. See the "What changed" table in `03-mern/README.md`.
