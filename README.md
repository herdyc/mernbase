# Stack Ladder

**One app, four stacks.** The same Study Planner (add, edit, complete, filter and delete tasks) built four times, from plain HTML up to a full-stack framework. Each rung adds exactly one big idea, so you can see what every layer of a modern web stack is *for*.

Made for students learning web development **hands-on, without AI writing the code for them**. Every rung has a README explaining what changed and a set of exercises with checks.

| Rung | Stack | The new idea | Run it |
| --- | --- | --- | --- |
| [1](./01-vanilla) | HTML, CSS, JavaScript | The DOM, events, state → render | open `index.html` |
| [2](./02-astro) | Astro + Preact | Components, layouts, build-time HTML, islands | `npm run dev` |
| [3](./03-mern) | MongoDB, Express, React, Node | A server, a database, accounts, an API | `npm run dev` |
| [4](./04-tanstack) | TanStack Start | One full-stack project: server functions, SSR, shared types | `npm run dev` |

## How to use it

1. **Go in order.** Read a rung's README, run it, then do its exercises *before* opening the next rung.
2. **Diff the rungs.** The same feature exists in every rung. Put two versions side by side, for example "add a task":
   - `01-vanilla/app.js` → the `submit` listener
   - `02-astro/src/components/Planner.tsx` → `addTask`
   - `03-mern/client/src/components/Planner.tsx` → `addTask` + `server/src/routes/tasks.ts`
   - `04-tanstack/src/routes/index.tsx` → `addTask` + `src/server/tasks.ts`
3. **No AI for the exercises.** Use docs, the code in earlier rungs, and your own debugging. The point is to build the instincts AI can't give you.
